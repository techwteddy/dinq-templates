# Contributing to FocusFlow AI

Thank you for your interest in contributing! This project is built for the community.

## How to Contribute

1. **Fork** the repository
2. **Create a branch** for your feature: `git checkout -b feature/your-feature-name`
3. **Make your changes** with clear, descriptive commits
4. **Test locally**: `npm run typecheck && npm run lint`
5. **Submit a Pull Request** with a detailed description

## Code Standards

- **TypeScript strict mode** — no `any` types without justification
- **Tailwind CSS** for all styling — no inline styles
- **Framer Motion** for animations — keep them subtle and accessible
- **Server Components by default** — use `'use client'` only when needed
- **RLS policies** — any new table must have RLS enabled with proper policies

## Reporting Issues

Use GitHub Issues with one of these templates:
- 🐛 **Bug Report** — include steps to reproduce, expected vs actual behavior, browser/OS
- ✨ **Feature Request** — describe the use case and proposed solution
- 📱 **Play Store Issue** — include Android version, device model, and TWA behavior
