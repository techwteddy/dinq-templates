# Screenshots

Drop your PNG screenshots here with these filenames so the README renders them:

- `feed.png` - home feed with stories rail
- `reels.png` - vertical reels viewer
- `stories.png` - story viewer
- `profile.png` - profile page with post grid
- `messages.png` - DM thread
- `compose.png` - new post / new story composer

Recommended size: **390 x 844** (iPhone 14 portrait) or any 9:19 portrait ratio.

**Quick way to capture:**

1. Run `npm run dev`
2. Open Chrome DevTools (F12) > toggle device toolbar > pick iPhone 14 Pro
3. Navigate to the screen you want
4. In DevTools, click the three-dot menu > **Capture screenshot**
5. Save the PNG to this folder with the filename above
