# 🚀 Personal Portfolio Website

A modern and fully responsive **Personal Portfolio Website** developed using **HTML, CSS, and JavaScript** to showcase projects, certifications, technical skills, and professional experience in Data Analytics and Business Intelligence.

This portfolio combines interactive UI design, animated analytics-inspired visuals, and responsive layouts to create a professional online presence for recruiters and hiring managers.
