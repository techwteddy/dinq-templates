# 🎉 عملية ضغط الصور التلقائية

## 🎯 كيفية العمل:

### الخطوة 1️⃣: حط الصور في المجلدين

```
📁 Cards_Photos/
   ├─ صورة1.jpg
   ├─ صورة2.jpg
   └─ ...

📁 Heart_Photos/
   ├─ صورة1.jpg
   ├─ صورة2.jpg
   └─ ...
```

---

### الخطوة 2️⃣: رفع على GitHub (مرة واحدة)

```bash
git add .
git commit -m "Added original images"
git push
```

---

### الخطوة 3️⃣: GitHub يشتغل السحر 🪄

✨ **بعد الضغطة:**

```
GitHub Actions يشتغل تلقائياً:
  1️⃣ يحمّل الكود والصور
  2️⃣ يشغل السكريبت compress_images.py
  3️⃣ يضغط جميع الصور بتلقائي
  4️⃣ يحفظ الصور المضغوطة
  5️⃣ الموقع بتاعك يستخدم النسخة المضغوطة
```

---

## 📊 النتائج التلقائية:

| | قبل | بعد GitHub Actions |
|---|---|---|
| 📸 صور البطاقات | 5 MB × 12 = 60 MB | ~3 MB (ضغط تلقائي) |
| ❤️ صور القلوب | 3 MB × 27 = 81 MB | ~6 MB (ضغط تلقائي) |
| **وقت التحميل** | 20 ثانية | 1 ثانية 🚀 |

---

## 🔄 كل مرة تضيف صور جديدة:

```
1. حط الصور في المجلدات
2. اضغط:
   git add .
   git commit -m "صورة جديدة"
   git push
3. GitHub يضغطها بنفسه تلقائياً ✅
```
