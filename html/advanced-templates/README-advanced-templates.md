## Overview

This folder is not a normal website template collection.

It is an **advanced website creation system** made to help build websites that look, move, and interact better than standard HTML/CSS/JS templates.

The system is designed for:

- Premium business websites
- Immersive landing pages
- Creative agency sites
- SaaS/product websites
- Interactive portfolio sites
- High-end local business sites
- Experimental one-page websites
- WebGL/Three.js-powered website experiences

The goal is to avoid generic layouts and instead create websites with:

- Cinematic storytelling
- WebGL/canvas backgrounds
- Particle systems
- Custom cursors
- Scroll-triggered animation
- Marquee/ticker sections
- Interactive cards and panels
- Magnetic buttons
- Glitch or luxury motion effects
- Premium typography
- Mobile-safe performance

## Antigravity Usage Guide

Use Antigravity design when the website should feel modern, floating, futuristic, or premium.

### Antigravity Hero Ideas

```text
- Floating glass dashboard card beside the headline
- Layered hero panels with soft shadows and perspective
- Background particles drifting behind translucent UI
- Product mockup floating in 3D space
- Cards that tilt subtly on mouse movement
- CTA button that feels magnetic
```

### Antigravity Section Ideas

```text
- Floating bento grid
- Isometric feature blocks
- Layered glass pricing cards
- Scroll-stacked service panels
- Interactive product demo cards
- Floating testimonial orbit
- Timeline with depth layers
```

### Antigravity Motion Ideas

```text
- Cards enter with vertical lift and slight rotation
- Background moves slower than foreground
- Mouse movement shifts layers at different speeds
- Buttons gently attract cursor movement
- Panels scale and lift on hover
- Scroll progress changes background intensity
```

### Antigravity CSS/JS Concepts

```text
transform: perspective(1000px) rotateX(...) rotateY(...);
backdrop-filter: blur(18px);
box-shadow: layered soft shadows;
translate3d(...) for GPU-friendly movement;
IntersectionObserver for reveal timing;
requestAnimationFrame for cursor/mouse smoothing;
prefers-reduced-motion fallback;
```

## Performance Checklist

Before publishing an advanced site, verify:

```text
- Canvas/WebGL does not cause mobile lag
- Particle count is reduced on small screens
- prefers-reduced-motion is respected
- Animations use transform and opacity where possible
- Scroll handlers are not heavy
- requestAnimationFrame is used carefully
- Large blur/filter effects are limited
- No horizontal overflow on mobile
- Touch targets are at least 44px
- Text remains readable over backgrounds
- Forms are usable on mobile
```

---

## Accessibility Checklist

Before using an advanced site publicly, verify:

```text
- Text contrast is readable
- Form inputs have labels
- Buttons have clear text
- Links are keyboard accessible
- Custom cursor is not required for usability
- Motion has a reduced-motion fallback
- Images have alt text
- Navigation works on mobile
- Important information is not hidden behind hover-only effects
```
