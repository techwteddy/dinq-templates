# Digital Agency – Multi-Page Website Template (React + Vite + TypeScript)

This project is a modern, full-featured website template designed for professional service businesses such as SEO agencies, consulting firms, or creative studios. Built with *React, **Vite, **TypeScript, and **Tailwind CSS*, it provides excellent performance, clean architecture, and extensive customization options.

---

## 🚀 Features Overview

### 🏠 Pages
- *Multiple Homepages*:
  - / – Default business homepage
  - /seo-agency – SEO agency layout
  - /consulting – Consulting firm layout
- *Core Pages*: About, Services, Pricing, Contact
- *Portfolio & Blog*: Showcase work and publish content
- *404 Page*: Included for proper routing fallback

### 🎨 UI & Interactivity
- *Radix UI*: Accessible component primitives (modals, accordions, dialogs, etc.)
- *Tailwind CSS*: Utility-first styling with custom themes and dark mode
- *Framer Motion*: Smooth animations
- *Swiper.js*: Interactive sliders
- *React Helmet*: SEO-friendly metadata control
- *Lucide Icons, Font Awesome, Heroicons*: Rich icon library

### 📦 Tech Stack
- *Framework*: React + Vite
- *Language*: TypeScript
- *Routing*: React Router with lazy-loaded routes
- *Data Fetching*: Axios + TanStack Query (React Query)
- *Forms*: React Hook Form + Zod (schema validation)
- *Notifications*: sonner (toast system)
