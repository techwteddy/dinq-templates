## 3D Vehicle Showcase

An interactive 3D vehicle website built using React Three Fiber and Three.js.  
The application allows users to explore 3D vehicle models and customize their colors in real time.

### Features

- Interactive 3D vehicle models
- Real-time color customization
- Smooth camera controls
- Responsive modern UI
- WebGL rendering using Three.js
- Tailwind CSS styling

### Tech Stack

Frontend
- React
- React Three Fiber
- Three.js
- Tailwind CSS

3D Tools
- Blender
